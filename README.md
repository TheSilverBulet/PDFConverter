# PDF Converter('s)

Some helpful scripts to turn either a single PDF into a text file, or a folder full of PDF's into a folder full of text files.
These scripts will purely convert the PDF('s) they will not format them in any way.

## Install required pieces

```bash
  pip install pdfminer.six
```

## Run a script

```bash
  python [singlePDFToTxt.py | PDFDirToTextDir]
```
The script utilized will prompt you for the required paths
